= Chart Data

This repository contains the authoritative data of the Chronostratigraphic Chart produced by the International Commission on Stratigraphy, distributed online at https://stratigraphy.org/chart.

This data is in the form of a https://en.wikipedia.org/wiki/Knowledge_graph[Knowledge Graph] formulated according to https://en.wikipedia.org/wiki/Semantic_Web[Semantic Web] principles, which means it's serialized in https://en.wikipedia.org/wiki/Resource_Description_Framework[RDF] and, after loading, can be queried using the https://en.wikipedia.org/wiki/SPARQL[SPARQL query language].

The Chart is formulated as a https://www.w3.org/TR/skos-primer/[SKOS Vocabulary] with many additional properties relevant to timescales and geology.

This data form of the Chart will soon be used to produce all PDF and other visual forms of the Chart.

== Creating a Release

To publish a release, go to the GitHub releases page and create a new release. This release should be set to create a new tag using SemVer preceded by `v`, but the major and minor versions should reflect the stratigraphic versions, for example `v2023.09.1`.

Publishing the release triggers a workflow that generates the PDFs and attaches them to the release.

== Development

Make UI changes in `chart-ui/`.

Install dependencies and run the UI locally from that directory:

[source,bash]
----
cd chart-ui
pnpm install
pnpm run dev
----

The development server runs at http://localhost:3000.

Visual changes affect the generated PDFs, so any layout, typography, spacing, or other presentation change should be tested locally by running:

[source,bash]
----
task test-pdfs
----

This installs the locked chart dependencies and PDF tools, builds the static chart, and writes the Main PDF plus every
language variant into `output/pdf/`. Google Chrome or Chromium must be installed. On macOS, Google Chrome is detected
automatically; otherwise set `CHROME_PATH` or pass `--chrome-path /path/to/chrome`.

To preview only English and European Portuguese, plus the Main PDF:

[source,bash]
----
task test-pdfs -- --languages en,pt-pt
----

The local command and GitHub Actions both call `.github/scripts/build-pdfs.mjs`, which discovers the chart version and
languages from `chart.ttl` and calls the same headless Chrome PDF exporter with `scale=print`. GitHub Actions supplies its
already-generated static build through `--build-dir chart-ui-build`; local runs build the current source first. Nothing is
published by the local command. Fonts available on your computer can differ from the GitHub runner's fonts.

Every export is checked for exactly one A3 landscape page. If the notes overflow, publication credits are moved into the
available lower margin beneath the second and third chart columns, preserving the chart geometry and font sizes. If the
result still does not fit, the build fails instead of saving or publishing a multiple-page chart.

After dependencies are installed, you can also run the builder directly:

[source,bash]
----
node .github/scripts/build-pdfs.mjs --languages en,pt-pt
----
